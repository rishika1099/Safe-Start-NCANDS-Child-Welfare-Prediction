## The Data

### acs_scr_reports.csv
Simulates the **Statewide Central Register (SCR)** — the intake system for child abuse and neglect reports in NYC.

| Column | Description |
|---|---|
| report_id | Unique SCR report identifier |
| family_id | Family identifier (families appear multiple times) |
| report_date | Date of report (2021-2024) |
| borough | NYC borough (Bronx, Brooklyn, Manhattan, Queens, Staten Island) |
| child_age | Age of child at time of report |
| child_race_ethnicity | Race/ethnicity of child |
| allegation_type | Type of alleged maltreatment |
| reporter_type | Who made the report |
| reporter_accuracy_score | Historical substantiation rate for this reporter type |
| assigned_caseworker_id | Caseworker assigned to investigate |
| caseworker_caseload | Number of active cases for this caseworker |
| narrative | Free-text case narrative (NLP target) |
| outcome | Investigation outcome |

### acs_features.csv
Engineered features used as inputs to the predictive risk model.

| Column | Description | Missingness |
|---|---|---|
| prior_reports_12mo | Reports in last 12 months | None |
| prior_substantiated_flag | Prior substantiated report (0/1) | None |
| days_since_last_report | Days since previous report | **62.9% — structural** (NA = no prior report) |
| child_age_under_5 | Child under 5 years old (0/1) | None |
| dv_history_flag | Domestic violence history (0/1) | None |
| substance_use_flag | Caregiver substance use concern | **14.8% — MAR** |
| shelter_involvement_flag | Shelter system involvement (0/1) | None |
| days_to_first_contact | Days until first caseworker contact | **7.9% — data entry gap** |
| reporter_accuracy_score | Historical reporter accuracy | None |
| caseworker_caseload | Caseworker caseload size | None |
| needs_investigative_consultation | **TARGET**: 1 = needs consultation | None |

## Key Domain Concepts

### Why Group-Aware Splitting Matters
The same family appears multiple times in the dataset. Random splitting puts different reports from the same family on both sides — the model trains on a family's history and "predicts" on that same family. That's leakage.

**Solution:** Split at the family level using `group_vfold_cv(group='family_id')`.

### Why Missingness Is Informative
A blank `substance_use_flag` doesn't mean the risk isn't there — it means a caseworker with 70+ cases didn't have time to document it. Always create missingness indicators before imputing.

### The Threshold Is an Operational Decision
The default 0.5 threshold assumes false positives and false negatives cost the same. They don't. Use F2 score (recall-weighted) and set the threshold in conversation with caseworker supervisors based on daily referral capacity.

### FATML: Fairness, Accountability, Transparency
A model with high overall AUC-PR but higher false positive rates in the Bronx than Staten Island is NOT equitable. Always disaggregate performance metrics by borough before deployment.

### Causal Inference at the Threshold
ACS assigns consultation based on a risk score threshold. Cases just above vs just below the threshold are nearly identical in risk — enabling a **Regression Discontinuity Design** to estimate the causal effect of consultation on outcomes.
